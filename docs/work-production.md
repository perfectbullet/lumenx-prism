# 作品级实体、素材与按集制作

导航：作品库 → 剧本制作规划 → 实体提取 → 图像制作台 → 分镜制作台 → 视频制作台。MiniMax-H3 的制作规格、简报、大纲、角色/场景卡、六列镜头表在各页衔接；不强制采用其默认3D画风。

## 时长

每集固定时长默认空，制作偏好2～5分钟。分集输出分别记录 source_duration（原文标注）、estimated_min/max＋timing_basis（独立内容估时）、target_duration（可编辑制作预算）。旧版本不伪造估时值，显示旧记录未提供。规划默认参考已确认集预算，手动覆盖收进折叠项；场次 estimated_duration 不允许倒推凑预算。第N集、第N场使用中文，8～180秒是单个制作段限制，不是整集或视频模型的长度。

## 联合提取与确认

实体页可多选/全选集。`work_entities` 文本任务读取原文及已确认版本，冻结作品已有实体外观目录，使用 entity_extraction 模型绑定。模型提出人物/场景/道具、已有 asset_id/variant_id 关联、身份特征、服装和每集原文引用。引用必须出自对应集；跨作品、跨类型或不存在的关联拒绝。

`prism_work_assets` 保存作品身份；`prism_work_variants` 保存外观和服装、选定图片及 edition/episode 出场关系；`prism_entity_confirmations` 记录确认来源。新身份重复换装使用显式 new_identity_key，不按名字直接合并。同名不同人可以独立；别名或不确定关系由人检查。确认页可复用已有外观，或沿用身份新增外观。复用不会覆盖原描述/选图，历史任务快照不变。提取结果需点击确认才入素材库。

## 缺失图片批次

图像页选择作品、版本、多集，展示已确认外观、统一风格和候选。`prism_image_batches` 持久化缺失素材清单及外观快照。文本 worker 调度 image_polish 子任务，成功后提交普通 image_generation 子任务（每项4张、角色先全身图）；生成仍由 GPU worker 执行。仅自动使用审核过的输入约束，解析校验仍会拒绝改写固定身份特征。

批次每项持久化阶段/子任务，幂等键由批次及外观确定，重启不会重复提交。外观使用 active_batch 原子预约，重复点击的另一批次跳过在途项。润色失败不执行图像调用，失败项释放预约，重新点击可补齐。已选外观跳过。成功后只有 selected 为空才自动选第1张，人工选图不会被迟到结果覆盖；候选选择检查外观归属及 revision。图片页可改选四张候选并查看原图。

## 分镜与视频筛选

分镜/视频页都可选择作品、版本与集；读取该来源下的制作规划和分镜版本。分镜页显示各场入口，进入本场时预填已选素材；同名多外观有歧义时不自动指定，仍需人工绑定。按集刷新保留过滤条件。作品任务查询兼容直接 work_context、场次快照及视频的 board 快照。旧任务不猜测归属，仍可按旧链接查看。

本次没有实现跨场整集自动合成；现有自动/手动候选合成为当前分镜版本2～36镜。多集实体仍需人工核对，原文证据通过不代表语义判断必然正确。

## 新增接口

- POST/GET `/v1/works/{id}/entities/jobs`；POST 使用 edition_id、episode_ids 与 Idempotency-Key。
- POST `/v1/works/{id}/entities/confirm`：成功任务ID和确认后的提议。
- GET `/v1/works/{id}/assets?edition_id=...&episode_ids=E01,E02`。
- POST/GET `/v1/works/{id}/image-batches`；POST 使用选择范围、可选 variant_ids、Idempotency-Key。
- PUT `/v1/works/{id}/assets/{variant}/candidate`：job_id、media_id、revision。
- GET `/v1/works/{id}/production?edition_id=...&episode_id=...`：本集规划、分镜和素材。

这些均为 Prism 实验制作数据，不写 LumenX 业务库，也不改变正式资产职责。模型配置只读取 model_comfigs。

## 图片历史筛选

图像制作台的任务区跟随当前作品、分集方案和所选集；未选作品与集时不展示全库历史。分类“全部／人物／场景／道具”与名称搜索只筛右侧任务，不修改生成表单。数量统计和分页在服务端执行，跨集复用外观的任务去重显示；“全部”包含该范围内自由图片。旧任务无作品关联时不猜测归属。点击任务查看结果，恢复原输入需明确点击对应按钮。

## 分镜制作台入口

页面按作品与集选择已确认制作规划，再选择场次并点击“载入本场”。移除旧实体任务导入入口；分镜名称自动生成，本场原文只读且默认折叠。场次摘要、时长、镜头数及素材随确认规划载入。切换来源清空旧场次并禁用提交，避免误用旧输入。已有历史分镜仍可查看与保存；新的页面提交统一走按场接口。

## 视频制作台刷新

“刷新作品列表”只更新作品与分集选项，保留当前范围、分镜和候选；未选作品时刷新最近制作概览。“更新模型列表”只读取可用模型并保留当前模型选择。“刷新概览／刷新候选与状态”位于结果区，读取当前概览或分镜的任务及合成状态，不提交生成任务。相同状态的合成预览不重复创建播放器。

## 屏幕内容与实体素材

场次 required_assets 仅列需要参考图的实体。screen_contents 保存电子文档/界面名称、carrier（必需素材中的物理屏幕）、原文引用、内容描述和需后期合成的原文文字。载体仍必须绑定图片；屏幕内容不生成独立道具图，也不从原剧情中删除。保存时校验来源原文与载体，禁止将同一内容同时列为必需道具。文字合成本身尚未实现，此处记录制作要求并避免让视频模型强画清晰文字。

已保存规划返回 reference_review，预先列出未确认实体、缺图或多个候选。修正规划时，旧内容留档到 script_plan_revisions，任务快照保持不变。纸质笔记本和笔记本电脑按当前场次动作区分，明确的场次修正不改变作品其他场次的实体身份和别名。

## 按场分镜的叙事检查

人物/素材引用、镜头顺序、总时长和逐秒覆盖继续作为结构硬校验。按场制作不将每场视为完整短片：开场/结尾钩子与连续三镜的节奏检查保留为带具体镜号的 warnings，editorial_checks 标记 needs_review，供保存确认时审阅；不改写原模型输出或伪造钩子标签，也不宣称完整创作自检已通过。无 scene_context 的独立短片入口保留原严格规则。已有按场失败任务可复用已保存输出重新校验。

## 视频生成与合并分离

视频制作台自动读取 MongoDB 默认绑定，显示实际生成模型（当前适配 H3）。模型切换、刷新可用模型和种子收进“高级生成设置”；只展示已接入的可执行视频协议，刷新不下载权重、不生成任务。

独立 `/tools/merges` 视频合并页按作品、集和一份镜头方案查看有序清单、成功候选及实际时长；支持自动选择、合并手动候选与全部合并，保留原音轨。视频页“前往视频合并”带入方案、版次和本浏览器的候选选择；刷新后校验候选归属。提交仍使用已有异步合并接口和幂等键，缺失镜头不跳过，当前不跨场或跨方案合并。

合并是 CPU/FFmpeg 任务，由非 GPU worker 消费，不再等待视频推理队列；GPU 暂停不阻止合并。旧进程在途视频任务不中断，新调度通过数据库原子领取避免重复执行。

视频合并页选择作品、集即自动应用，移除重复的“载入选择”按钮。重复应用相同范围保留当前镜头方案、候选及预览；仅切换作品、分集方案或集时清空旧清单。“刷新作品列表”用于重新读取选项并保留制作状态，右侧“刷新候选与状态”用于更新当前镜头方案的视频与合并记录。
