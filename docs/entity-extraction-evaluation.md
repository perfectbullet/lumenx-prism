# 剧本实体提取：中文基准与评测方法

本基准评测 `POST /v1/scripts/extract-entities`，不涉及项目持久化、正式 UUID 或业务权限。机器可读剧本及人工参考答案位于 `tests/fixtures/entity_extraction/rainy_station.json`。参考答案是人工编写的测试数据，不是模型生成结果。

## 中文剧本

第一场：旧钟表铺，傍晚。橱窗透进暖黄光，墙上挂满旧钟。林岚是28岁的女性，黑色短发，左眉有一道浅疤，穿米色风衣和黑裤。陈伯是62岁的男性，灰色短发，穿深蓝围裙。林岚把一把齿部缺了一角的黄铜钥匙交给陈伯。陈伯将钥匙装进红布包，递还给她。林岚皱眉说：“周叔今天没来。别担心，我没带手枪。”周叔全程没有出场。

第二场：河湾车站候车厅，夜晚。冷白顶灯照着空荡的候车厅，窗外下雨。林岚已经脱下风衣，换成深蓝工作服，黑色短发和左眉浅疤未变。她抱着同一个红布包，取出里面的黄铜钥匙，又把一个未封口的牛皮纸信封交给陈伯；陈伯仍穿深蓝围裙。她快步离开。

第三场：旧钟表铺，次日清晨。同一间铺子，晨光照着挂满旧钟的墙。陈伯仍穿深蓝围裙，手里拿着那个牛皮纸信封。

## 标注与验收标准

| 维度 | 本样本必须满足 |
|---|---|
| 实体完整性 | 两个身份：林岚、陈伯；角色条目3个（含林岚服装变体）；场景2个；道具3个 |
| 稳定外形 | 林岚两条均保留黑色短发、左眉浅疤、28岁、女性；陈伯保留灰色短发、62岁、男性 |
| 服装变体 | 基础条目名为林岚，服装为米色风衣和黑裤；变体名为 `林岚 (深蓝工作服)`，不推测换装后的裤子、鞋子；陈伯仅一条，深蓝围裙 |
| 场景准确性 | 旧钟表铺保留挂满旧钟的墙、橱窗、傍晚暖黄光和次日晨光；候车厅保留夜晚、冷白顶灯、空荡及窗外雨；同铺跨时段不重复创建 |
| 道具准确性 | 黄铜钥匙保留材质和齿部缺角；红布包保留颜色及材质；牛皮纸信封保留材质及未封口；反复转手不增加条目 |
| 幻觉 | 不创建周叔、手枪、额外地点、人物或物品；不发明眼睛颜色、身高、职业、亲属关系或信封内容；墙上旧钟作为布景，不另创建剧情道具 |
| 临时状态 | 不把皱眉、快步离开写成固定外形，不把物品持有者写成物品永久属性 |
| HTTP 契约 | 三数组齐全；引用编号全局唯一（编号本身不要求与参考答案相同）；权重1～5；无项目ID、正式UUID或服装关联字段 |

语义等价表述可接受，例如“眉部浅疤”“女/女性”，不按描述字符串完全相等评分；变体的半角括号命名须保留，以适配现有业务关联逻辑。具体临时编号、数组顺序、合理的重要度差异不影响语义通过。

实体召回率 = 正确匹配的预期条目数 / 预期条目数，分别计算角色(3)、场景(2)、道具(3)。精确率 = 正确匹配条目数 / 返回条目数，重复条目按误报计。属性覆盖率 = 正确保留的明示事实数 / 上表要求的明示事实总数；另列错误属性与无依据属性，不能用高覆盖率抵消幻觉。

本小样本的通过条件：各组召回率及精确率100%，上表事实无遗漏或错误、无依据属性0条，换装身份与契约全部正确。空数组不能通过这个样本；对空实体文本则允许空数组。单一样本通过不足以说明泛化效果。

## 免费验证及已知限度

```bash
conda activate lumenx_prism
python -m pytest
python -m pytest tests/test_chinese_sample.py tests/test_output_parsing.py
```

中文样本测试把人工参考 JSON 作为模拟模型输出，经真实 FastAPI 路由回放，覆盖原文传递、纯/围栏 JSON、描述与变体字段保留和业务字段边界。它验证处理链路，不验证模型能否从原文正确推理。独立进程 HTTP 测试另外覆盖 Prism 与本机模拟 provider 交互，不接触真实 provider。

异常输出实验发现：旧解析器接受重复字段并覆盖前值，也允许 NaN/Infinity 隐藏在扩展字段中。回归测试先复现失败，再修复为 `502 invalid_model_output`。正常字段、默认值、可选字段、围栏输出及错误码保持兼容。不使用正则抓取局部 JSON、静默修补或额外模型调用掩盖错误。

样本标注也暴露了旧提示词“估计年龄”与事实准确性目标冲突、换装命名不够明确、否定/仅提及实体缺少规则，因此默认提示词增加事实约束、未知字段留空、去重与半角括号规则，并移除 JSON 示例注释。这是基于人工样本的规则改进，真实模型收益尚未验收。自定义提示词仍按原契约覆盖默认提示词。

结构合法不等于语义正确；当前运行时不自动判定文本是否支持每条事实，也不生成语义质量分数。

## 获得真实模型调用授权后的评测

此阶段单独明确模型、调用次数及费用上限后再进行，本次不执行。先确认 Prism 自己的凭据可用，固定模型/提示词版本，用相同剧本对比改动前后输出。逐项填写上表及精确率/召回率，记录漏提、错提、重复、换装错误与无依据属性。输出及实验记录保存在本地忽略的 `docs/agents/`，不提交凭据或个人材料。

真实输出如解析失败，保留脱敏失败类型，在本机增加最小回归样例后改解析器；语义错误优先迭代提示词与样本，避免硬编码当前人名或道具。另需补充未知年龄、别名、无服装变化、空实体、长文本及文本内指令等样本，再决定业务切换。原始剧本、供应商错误与鉴权信息不得进入 HTTP 错误响应。
